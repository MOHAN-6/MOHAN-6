### 🛠️ Featured Projects

#### 🔍 AI-Ready Log Analytics & Monitoring System
[![Live Demo](https://img.shields.io/badge/Live_Demo-000000?style=for-the-badge&logo=render&logoColor=white)](https://ai-log-analytics.onrender.com/)
[![Repo](https://img.shields.io/badge/Source_Code-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/MOHAN-6/ai-log-analytics)

An enterprise-grade log analytics platform built for scale and speed.
- Handles **500 concurrent requests** at **17ms avg response time**, processing **1M+ logs** with a **60% latency reduction**
- High-performance, time-partitioned log storage with cursor-based pagination (**15ms query latency**)
- **Isolation Forest** for anomaly detection + **Naive Bayes with TF-IDF** for severity classification (INFO/WARNING/ERROR/CRITICAL)
- Real-time analytics dashboard with severity distribution, service breakdown & time-series visualization
- Bulk ingestion pipeline supporting **10,000 logs/batch**
- Containerized with Docker, deployed via **CI/CD (GitHub Actions)**
